# Bundled application fonts

These unmodified fonts are embedded for UVEL's own UI. This directory is not a font distribution service.

- Inter: the variable WOFF2 subsets `latin`, `latin-ext` and `vietnamese` (weight 400–600, optical size 14–32) exactly as served by the [Google Fonts CSS endpoint](https://fonts.googleapis.com/css2?family=Inter:opsz,wght@14..32,400..600&display=swap), retrieved 2026-10-29 and stored as `Inter-latin.woff2`, `Inter-latin-ext.woff2` and `Inter-vietnamese.woff2`. Retain `INTER-OFL.txt`, copied from the [Inter project](https://github.com/rsms/inter/blob/master/LICENSE.txt). SHA-256: latin `dd8a4575be9806105ac3decd02805cd2782fe7c05abb02c582316bc436ce03ae`, latin-ext `8bc9dee39deab5dc6599980e563c5023053387e4c391f5c419543e493e024c39`, vietnamese `07df696d36deed379a901c2867fd700fee3453f46e384424a08ee376178a81b1`.
- General Sans 400/500/600: original WOFF2 files supplied by [Fontshare's CSS endpoint](https://api.fontshare.com/v2/css?f[]=general-sans@400,500,600,700&display=swap), retrieved 2026-09-27. Retain `GENERAL-SANS-ITF-FFL.txt` (ITF FFL 2.0); do not subset, convert or redistribute as a font collection. [Official license](https://www.fontshare.com/licenses/itf-ffl). Declared as "UVEL Figures" for digits and numeric symbols only (DS-26). SHA-256: 400 `3ec2be771caf168b077ca05af4df1dace77088e2b3a27da570036e61be58a039`, 500 `c30377df1de8444d07161725c751f458beec07c28034df2fd275d1aa587a239f`, 600 `94a2a0e1ef59728eb65498ed7fe26e5af7e2858a3a4a278a89ac1f83a0544945`.
- Montserrat: the variable WOFF2 `latin` subset (weight 500–600) exactly as served by the [Google Fonts CSS endpoint](https://fonts.googleapis.com/css2?family=Montserrat:wght@500..600&display=swap), retrieved 2026-10-30 and stored as `Montserrat-latin.woff2`. Retain `MONTSERRAT-OFL.txt`, copied from the [Montserrat project](https://github.com/JulietaUla/Montserrat/blob/master/OFL.txt). Declared as "UVEL Balance" for the wallet card balances only (DS-26). SHA-256 `6438d7b8ea9c7c3992d5e2fd2afdb1ff948570a3ef0bedae76247b51632960ba`.
- JetBrains Mono: original `JetBrainsMono[wght].ttf` from [google/fonts](https://github.com/google/fonts/tree/23e54b51ddffbc7713c583748e3bd86f62b1fa4a/ofl/jetbrainsmono), stored as `JetBrainsMono.ttf`. Retain `JETBRAINS-MONO-OFL.txt`. Used for addresses, hashes and codes read character by character, and the live figures behind `.font-mono-tabular`.

All binary font data is unchanged. `src/styles/fonts.css` declares each Inter subset with its original `unicode-range`, so a page loads only the subsets its text needs; Chinese falls through to the system fonts. These files and licenses are copied into the application build through uni-app's static asset pipeline.

Manrope was retired on 2026-10-29 (DS-25): General Sans could not draw Vietnamese stacked diacritics, and patching those code points with Manrope mixed two designs inside one word. Since 2026-10-30 (DS-26) General Sans returns for figures only, so every letter, including Vietnamese, stays on Inter.
