# UVEL 时间展示与加载稳定性

日期：2026-10-26。依据本轮用户批准方案，适用于正式 App test 与共享 H5；不改变任何业务结算、资产、购买资格或平台周期。

## 时间展示

- 普通事件以设备本地时间显示；银行业务仍使用越南 UTC+7 并标明时区。现有明确采用 UTC 的活动时间仍保留 UTC 标识。纯日历日期不转换时区。
- 中文日期为 YYYY/MM/DD，英文为 Oct 26, 2026，越南文为 DD/MM/YYYY。时刻采用24小时制，通常精确到分钟；原本需秒的交易、追踪等信息保留秒。跨年记录显示年份。
- 时间来源仍依各字段原接口契约。数值事件时间使用既定毫秒单位，Java 无时区时间继续按既有 Asia/Shanghai 解析；不通过数值大小猜测单位，也不使用设备当前时间补齐缺失。
- 无效、缺失或零事件时间显示占位。Android 原生不依赖可能忽略 locale/options 的 Intl 与 Date 本地化输出，不能出现英文 Date 原串或直接展示 ISO。
- 倒计时、冷却、结算和重置规则沿用现有服务端权威时间；展示规范不改变资格、日边界或有效期。
- 业务日边界跟随后台 A3「业务时区」（D-16）。App/H5 读取公开的 `GET /api/config/business-calendar`，按「其他模块」轨道切分本地判断用的业务日与周（大使申请日期、今日已完成任务、页面观测周），已排定的切换在生效时刻自动生效；读取失败保持上次成功结果，首次读取前按与后台一致的初始日历（北京时间）。兑换每日额度的重置时间按该轨道显示为「UTC+8 00:00」这类偏移。银行业务的越南 UTC+7、转盘与活动的 UTC 保持不变。
- 人工客服保留现有统一IM时间层级：气泡内24小时制时分，首条有效消息及相邻有效消息间隔至少24小时时使用居中分隔；跨午夜不足24小时不新增分隔。今天、昨天、星期标签保持，确实输出的绝对日期及完整时间提示、无障碍日期使用本轮三语格式并含年份；完整提示保留秒和时区偏移。不恢复旧气泡外时间排版，不改变消息顺序、回执、动画或滚动。AI 和系统提示原本未展示的日期元数据不作为本条已完成范围。
- 首页动态、收益页签及结算账本的历史记录包含完整本地日期与分钟；窄屏日期占可换行区域，保留最小行高并允许内容增长。该展示不改变金额精度、排序、条数、业务过滤或权限。
- 收益页任务中心的已完成任务记录显示完整本地日期与分钟，日期使用独立第二行；金额与回执图标保持可读。静态完成日期不再为相对时间启动30秒轮询，回执权限、排序和业务时钟保持。
- 创世市场的历史活动显示完整本地日期与分钟，跨年包含年份，无效或零时刻显示占位；日期在独立行自然换行，价格与描述保留完整文本，不改变成交排序、金额、交易门槛或期限。
- 可用代金券的到期日期完整显示，窄屏允许自然换行并增高卡片，不用省略号隐藏年份；面值与使用按钮保持可读。无到期日的原规则、券名、适用范围、资格和使用跳转保持。
- 法律文档元数据的纯生效日期按所选语言格式显示，不转换日历日期；原始文档、版本、管辖区、确认令牌及接受状态保持。
- 创世持仓已有挂牌时间、团队成员加入时间（关系树与成员网络节点弹层）、已提供解锁时间的成就条目与密码最后修改时间显示完整本地日期和分钟，跨年保留年份；日期自然换行，不截断金额、姓名或安全说明。在线设备的最近活跃状态继续采用原相对时间，未提供时间的正式成就条目不新增日期。
- 钱包在途提现显示可信提交日期，银行 BANK-VND 摘要使用越南 UTC+7 并标明时区，链上摘要仍用设备本地时间；远端缺少、无效或旧快照没有可信时间时显示“—”，不使用当前时间替代。展示来源与原业务排序、限额和恢复时间分开，金额、状态及资金操作不变。
- 服务列表的日期表示最近活动或更新时间，按本地完整日期与分钟显示并允许换行；保留现有会话更新与已载入消息的时间水位、排序和摘要，不将仅有更新时间的条目称为消息发送时间。

## 页面状态与缓存

- 消息中心服务列表及通告列表在当前分类已有内容时，后台刷新只更新忙碌状态，不插入或移除占流加载块；当前分类无内容时仍显示原加载提示。真实读取失败、重试、实时连接降级说明、分页与账号/分类清理保持，不以旧列表授予操作或掩盖错误。

- 原生五个底栏在当前会话中保留各自最近一组查询条件的页面实例，最多五个。返回已访问底栏保留已有普通内容、图片与滚动位置，并按原生命周期刷新最新数据；重复点击当前底栏仍回顶。
- 切换账号、账号绑定代次、语言或 API 环境时清空保留实例及对应滚动位置；同一底栏查询条件变化替换该底栏旧实例，不无限保留详情或筛选组合。
- 隐藏底栏必须收到隐藏生命周期，暂停页面计时、页面轮询和可见入口请求；再次显示时恢复时钟/读取。页面卸载后释放相关监听和定时器。
- 原生栈内二级页和外部浏览器返回时，由实际视图滚动容器保存并恢复位置；隐藏/切换过渡产生的滚动钳位不得覆盖先前位置。同一帧快速往返底栏仍按各自查询与切换代次恢复。
- 配额同作用域的展示卡片在返回、刷新中和刷新失败时保留布局；读取未确认时库存、资格与购买操作保持未知或禁用，错误及重试明确可见。滚动恢复等待真实内容高度及可见标记就绪，用户主动滚动后停止待恢复动作。
- 复用现有 store 快照、请求合并与图片缓存；本轮不建立通用持久业务缓存。首次加载维持稳定布局，已有内容刷新避免无关区块反复消失或动画重放。
- 保留的页面实例首次隐藏后，返回时不重播卡片入场动画；新建实例仍保留首次入场，原生托管底栏从首帧直接显示，减少动态效果设置保持有效。
- 信任中心刷新状态与已有快照读取失败后的重试放在内容末尾，避免顶部临时状态行使分类和文档入口位移；首次读取失败仍在已展开分类内提供错误和重试。
- 团队周奖池后台刷新保留同账号的个人预估金额时，同时保留“预估”限定；失败或暂停且不可读时金额及限定均不展示，未解锁的奖池合计不冒充个人预估。
- 我的页面常驻两步验证摘要行，未知或读取失败显示“—”，已确认状态使用三语已开启/已关闭；不依据2FA布尔值声称已设置Passkey。同账号后台刷新保留已确认摘要，常用功能不因状态行插入而移位。账号、会话绑定变化立即清空，隐藏页和旧请求不得回填；摘要只用于展示与进入安全页，安全操作继续实时校验。
- 我的紧凑钱包预留一行桶状态及现有估值行，普通零值、加载、失败与恢复不再插入状态行。已确认零桶保留对读屏隐藏的空占位，失败或未知继续显示原占位，不补零。真实金额、较大字体等导致完整文本换行时允许自然增高，不截断金额；布局保留不授予余额、报价或安全操作资格。
- 同一内容键和所选语言的公开说明重试时保留已读正文，不清空重建；仅网络读取失败时保留正文，并在末尾提供明确错误和重试。首次无正文的错误仍显示在页首。内容键或语言变化立即清空旧文；认证、HTTP、业务拒绝、协议失效、未解析规则及必须发布的团队模板校验失败均清空，不用旧文替代。原不可用事件继续发送，展示正文不授予操作资格。
- 缓存仅改善展示。余额、报价、库存、资格、设备权限仍按现有实时读取/失效合同约束；旧数据不能使交易或任务按钮获得资格。真实失败保留简洁错误和重试；未知数值不补零。
- 多数量、组合及活动确认页在同一选择手动重读报价时，保留本页只读金额、优惠、支付和费用布局，避免内容收缩导致滚动位置重置；权威报价仍立即失效，刷新和网络失败期间不能确认或付款。网络失败保留明确错误与重试，严格拒绝、选择或账号等作用域变化清除旧展示，不持久保存展示快照。
- 离页、账号/环境/对象变化的旧请求继续由原作用域围栏隔离，不回写新页面、不重放未确认写操作。
- 同一会话打开原生图片预览后返回，保留之前的历史阅读位置，不将此返回当作普通重新进入而强制跟随最新消息；仍执行原私图、会话及权限重读。仅保留已测图片行的数值高度，重读期间不缩短阅读布局；仅当前来源、当前预留代次的图片在可见页完成加载后释放，迟到或隐藏期间的回调不释放新占位；不保留旧私图 URL、数据或授权。账号、绑定代次、会话、视图变化与卸载废弃旧恢复；普通重新进入、原本位于底部的新消息跟随和发送恢复规则保持。
- 原生逻辑层无 DOM 时，通过原生视图按唯一图片行标识读取实际高度；数值占位提交并读回确认后才打开原生预览。等待期间继续滚动、离页、换会话、图片或消息变化以及再次点击均废弃旧准备；当前图片仍有效但无法确认测量或占位时，使用原页面图片浮层，不以固定尺寸或延时替代测量。H5 沿用页面浮层与既有 DOM 行高路径。
- 同次原生测量包含每张图片的实际高度。私图重读重新创建图片期间，以该数值暂时约束图片的最小和最大高度，避免框架默认尺寸先把正文撑高；不绑定或擦除框架自身的图片高度。仅当前来源、当前预留代次与图片帧的有效加载，经可见视图布局回读确认后解除约束；未知尺寸和迟到回调不释放新占位。原私图权限重读、普通首入与 H5 图片预览保持，不缓存图片地址或内容。
- 每日签到连签权益的远程 `ROUTE_BADGE` 官方条目按当前语言展示独立名称：`ROYALTY_BOOST` 为团队成长徽章、`STREAK_BADGE` 为连续签到徽章、`STAKING_APY` 为质押活动入口、`GENESIS_ALLOWLIST` 为 Genesis 资格入口。行标题、动态页脚和原激活结果提示共用该展示；激活等待期间切换语言，完成提示读取当前同条目的展示名；不得套用旧 Mock 的佣金、UVT 或 APY 加成承诺。仅已知代码、效果类型及官方发布名称同时匹配时使用三语名称，未知、改名或其他效果保留发布名；不改发布记录、天数、效果、资格、奖励、激活命令、导航及业务暂停/未知闸门。Mock 展示保持原分支。
- 收益凭证的 asOf 协议日期仍按越南业务日校验，使用已解析服务端时刻的 UTC+7 日历生成比较值；不依赖设备 Intl 本地化输出。错误日期、来源、环境与事实字段仍拒绝，不因兼容原生而放宽权威验证。

## 弹层返回

- Android 收益或设备详情的产能与新机补贴说明弹层打开时，系统返回先关闭当前最上层可取消弹层并保留原页。全局确认与仅重试遮罩的优先级保持；无弹层、隐藏页面或底栏、程序导航返回时正常放行。关闭和商城 CTA、补贴计时及设备权限保持原规则，H5 保留原键盘和焦点行为。
- Android 成员网络打开成员详情弹层时，系统返回先关闭当前最上层可取消弹层并留在成员网络；无弹层、页面隐藏或程序导航返回时正常放行。卸载、账号清理或成员失效后不留下拦截，H5 保留原键盘与焦点行为；搜索成员结果仍沿用现有普通成员网络入口。
- Android 我的页面打开主题选择时，系统返回取消当前最上层可取消弹层，保留页面与已选择主题。全局确认框和仅重试遮罩维持既有视觉优先级，取消确认只返回否，不能触发确认操作或关闭下层主题。
- 隐藏页面或底栏、没有弹层、程序导航返回时正常放行；重复挂载主题不重复注册页面返回钩子。H5 沿用现有 Escape、焦点及点击关闭行为。
- 偏好页“清空已读”确认打开时，Android 系统返回只取消本页当前确认并保留偏好页；确认之上的仅重试网络遮罩保留。账号切换、离页或已取消确认的迟到结果不能清空通知；当前用户明确确认的原功能保持。

## 售后联系入口

- 信任中心的“联系售后”进入现有消息服务列表，使用当前账号既有会话的 cid 继续联系专属客服；导航本身不创建会话、不发送消息，不进入无参数空聊天页。公开资料链接的安全校验保持。
- 订单恢复区的“复制订单号并联系支持”先复制当前订单号，成功后进入同一服务列表，由用户选择既有会话；不自动发起咨询或发送订单号。复制失败、离页、订单或账号作用域改变后的回调不得导航。

## 兑换最大金额

- 兑换页沿用现有两位金额输入精度，最大金额按已确认可用余额向下取到两位，避免六位余额经四舍五入后误报不足。金额不足、未知余额、暂停、手续费、限额及确认校验保持；不足一分的余额不能形成可提交金额，截断余数仍留在原资产。此项不改变六位资产记账精度。

## 原生玻璃按钮图标

- 磨砂玻璃按钮内的原生 SVG 图标保持可见，返回、重试等图标不得被背景层遮挡；按钮点击区域与原操作语义保持。

## 课程结果返回

- 课程结果的“返回教程中心”复用当前连续课程链之前最近的已有教程中心，回退课程链而不再替换出第二个中心；连续“下一课”进入的多层课程适用同一规则。不得越过无关页面寻找旧中心；直接推荐进入、深链、无可确认中心或读栈失败仍前往明确的教程中心，回退失败沿用原替换恢复。普通页头返回的首页、任务及奖励来源、课程学习、测验、奖励和资格判断保持。

## 验收依据

- 消息中心已有结果的暖刷新失败时，固定导航的空余中区明确显示“更新失败 · 重试”，保留两侧返回、偏好与原刷新能力，不向标题、分类或已有结果前插入恢复行；通知及服务的完整失败说明和各自重试保留在当前结果后，冷态无结果时直接可见。未读失败保持未知，账号/分类清理、错误与命令权限不变；仅实时连接降级仍沿用原独立提示及重连重试，不视为本项几何验收已通过。

- 钱包累计收益的算力、团队及合计仅在同作用域后台读取期间保留已确认的展示值，待新结果替换；首读未知、缺项、失败或账号/运行作用域清理仍显示占位并沿用错误重试。此规则只涉及累计历史展示，不放宽今日收益、余额、可用资金、费用、释放资格或任何资金命令的实时校验。

以本轮逐功能台账、时间边界行为测试、真机镜像操作与关键录屏为准。构建、推送、安装和历史截图分别记录，不单独作为业务验收通过；缺前置和未实际操作分支保留待验。
