# H9 首页网络动态展示恢复（2026-10-30）

## 范围与数据源

首页「UVEL 网络动态」底部在线数恢复读取 H9 公开配置的 `networkPulse.onlineDevices`，与首页网络实况在线格共用来源。真实 Home 统计 `onGrid.activeDevices` 不参与该展示；H9 缺失、非法或读取失败时，不使用真实统计或客户端种子补值。

右侧每秒金额读取 `/api/config/home-display` 发布批次的 `paidCents` 相邻秒差，单位转换为 USDT/sec；不再读取真实 Home 的 `onGrid.perSecUsdt`，不使用累计已发放额直接充作秒增量，也不使用设备规模乘收益档位或客户端随机数。

客户名称、模型、城市、GPU 行继续只读取 Home 公开投影。H9 当前没有对应配置字段，不增加或伪造列表，不改变这些行的来源与语义。其他页面的数据来源本轮仅审计。

## 秒增量定义与时效

开启增长的合法批次至少包含 61 个等间隔一秒样本。当前样本下标由服务端时间与 `startAt` 的秒差向下取整，沿用已有批次播放器的时间对齐方式。

- 首样本的金额增量为 `(paidCents[1] - paidCents[0]) / 100`。
- 后续样本的金额增量为 `(paidCents[i] - paidCents[i - 1]) / 100`；末样本也采用前差，不读取数组末尾之外的样本。
- 合法暂停批次仅有一个样本，每秒增量为 0。
- 服务端时间达到 `validUntil`、样本耗尽、批次缺失或非法、读取失败时，该侧显示 `-`；暂停也受有效期限制。

该金额是 H9 已发布展示批次的每秒变化，不改变真实任务、余额、收益或已发放账务。介绍页继续显示已有累计已发放额；播放器新增秒增量字段不改变其累计值。

## 异常、重试与生命周期

在线数仅接受非负安全整数；0 是合法值。在线数与网络实况使用同一 `networkPopulationBand` 档位，中、英、越三语一致；未知显示 `-`。

两项独立降级。一项失败时保留另一项的有效数据，失效侧提供至少44×44触区的重试入口；两项均不可用时沿用统一反馈与重试入口，首批金额仍在读取时显示更新中，读取结束后仍无数据才显示不可用。在线数重读 H9 平台公开配置，金额重读已发放批次，不通过业务 Home 刷新替代。读取中的请求合并，避免重复请求；重试不清空另一侧的已确认值。

金额沿用共享可见页播放器：每秒本地采样已发布批次，每分钟刷新批次或在有效期到达时刷新；页面或文档隐藏后暂停采样与请求，返回时重取批次。返回时立即校验旧批次有效期，过期数据不等到下一次请求完成才隐藏。离开前的旧请求不得覆盖新一轮可见访问的数据；卸载时移除计时器和文档可见性监听。

界面不显示内部字段、接口或来源说明。沿用既有三语标题、在线文案与金额格式；明暗主题沿用现有设计变量。
