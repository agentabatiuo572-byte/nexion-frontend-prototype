# UI-OPT-026 邀请榜算力点口径

2026-10-28 用户确认：邀请榜所有周期的排名、榜单数值、与上一名的差距均以独立平台算力点为依据。此要求覆盖旧 v3.7 §8.11 中 USDT 排名、金额差距及金额列的描述；佣金、钱包、退款及实际奖励资产不变。

## 当前覆盖与缺口

APP 已合入 `b12a1ab0`，其中 `2c1b4fea` 将 network/quota/v-rank 改为 points-only。该提交未修改邀请榜：`src/api/team-insights-api.ts` 的原契约只有 `earnedUSDT`、金额差距 `gapToNext`。

本地正式后端源码 `AppTeamInsightsService.leaderboard` 仍从 `earnedUsdt` 生成榜单并以相邻收入相减生成差距。现有 network 的月度/累计点数不能替代全站邀请榜的四周期统计、排名和分页。

因此本轮是 APP 新契约兼容、展示与独立演示数据实现，**不代表正式后端已覆盖算力邀请榜**。未改后端、共享奖励规则或试用退款。下列独立字段和统计语义尚需正式后端发布、确认及验收。

## 增量 API 约定

端点仍为 `GET /api/app/team/insights/leaderboard`，保持原 period/page/pageSize/snapshotAt/snapshotVersion、来源、账号与环境围栏。

| 字段 | 新约定 |
|---|---|
| `rankingMetric` | `COMPUTE_POINTS` 明确证明 rank/myRank/totalRows 属于算力榜；缺少、null 或其他字符串均不构成证明。 |
| `rows[].computePoints` | 当前周期独立算力点，非负安全整数。缺失或 null 为未知；0 为确认零。不得从收入、金额、UVT 或设备 TOPS 转换。 |
| `gapToNextComputePoints` | 当前用户与上一名的同周期点数差，非负安全整数；缺失/null 为未知，0 可表示同分。不得取旧 `gapToNext`。 |
| `rank` / `myRank` | 由正式后端按同一算力点统计排序；同分顺序及入榜资格由后端发布规则决定，前端不推断。 |

原 `earnedUSDT`、`gapToNext`、`poolUsd` 保留其原资产含义，仅作兼容读取；本页不展示这些金额，也不将奖池金额改为算力点。独立点数响应可不含旧收入/差距字段。

后端尚待明确：哪些算力事件参与邀请榜、周期时区与边界、回滚/退款如何影响点数、入榜资格、同分规则、快照版本是否覆盖全部点数及口径。前端不新增上述算法或资金派发承诺。

## 页面行为与验收

- 标题为邀请算力榜，列头、差距和排序说明覆盖中英越，其他语言回退英文；沿用平台算力点格式化，不出现货币符号。
- 只有响应明确 `rankingMetric=COMPUTE_POINTS` 才展示该榜单的排名与名单。旧金额榜显示未知排名及“算力排行暂不可用”，不回退旧榜或本地演示。
- 已确认的算力榜中，单项点数或差距缺失显示 `—`，不伪造零。第一页、第一名、未入榜、同分、空榜、暂停/冻结、读取失败分别保持真实状态。
- API 校验已知点数按名次非增；前端不重新排列分页。后续页保留同一口径、周期、快照与连续名次，且不能在页边界出现更高点数。迟到响应、切账号/环境/语言、暂停和错误行为沿用现有围栏。
- 全局隐私隐藏时排名、人数、成员等级、点数及差距使用同一 `useDataVisibility` 遮罩，包括可访问文本；重新显示恢复真实值。公开单位与排序说明保留。
- 本地 mock 与 loopback demo 各有独立点数数据和点数差距，金额大小与点数名次刻意不一致以检验无金额回退。演示正常不代表正式端已迁移。
- 本轮仅针对测试、类型检查与源码证据；不构建、提交、推送或操作 5237，实景验收由主线程安排。
