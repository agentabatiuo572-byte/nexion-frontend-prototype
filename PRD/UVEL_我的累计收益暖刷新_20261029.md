# 我的累计收益暖刷新

日期：2026-10-29。适用于 App/H5「我的」累计收益和算力、团队拆分。沿用[团队静默暖刷新](UVEL_团队静默暖刷新_20261027.md)与[Tab 快切保护](../docs/PRD/UVEL_Tab快切保护_20261028.md)。

- 已取得同账号、绑定、语言、环境和业务上下文的累计金额时，普通 Tab 往返、后台暖读和仍持有效目录展示凭据的目录通知不清空原金额。算力与团队分别读取；仅两项均已确认时计算合计，首读未知不制造零。
- 网络、超时、HTTP 5xx 或 429 暂时失败保留已确认的只读累计金额。失败和原重试反馈继续显示；重试未结束时保留已有反馈，当前相应读取成功后撤销。429 沿用服务端重试期限，手动重试不绕过。
- 团队累计的只读金额与佣金事件权威快照分开保存于内存。重读及失败仍按原规则清除权威快照；此只读金额不参与提现、领取、成员操作或任何资格判断，不扩展资金权限。
- 同作用域、同请求代次的自动、手动和被动团队累计读取共用在途请求。运行时或绑定改变后启动当前代次读取，旧成功、旧失败和旧清理不能覆盖当前状态。失败资源不因保留只读数字而成为快切保护的成功缓存；下次有效访问仍能实际读取。
- 退出、账号或绑定、语言、环境、接口地址、真实运行时或业务写入使原上下文失效时撤销受影响的旧团队展示，并拒绝旧响应。401/403、协议、配置及其他严格拒绝撤销对应来源旧金额。我的合计在任一来源未知时为「-」。现有 Home/Earn 的请求与失效合同保持。
- 目录展示凭据失效会撤销旧团队金额；之后当前账号、绑定、语言和请求作用域内独立佣金 API 的新成功仍可建立新金额，不要求目录持续可用，也不能用旧缓存或旧请求恢复。
- 当前权威成功的零、未知或分页聚合替换旧累计数；不能无限保留旧完整金额。今日收益、确认中、待释放、隐私遮罩和操作资格沿用各自原合同。

本轮验证覆盖受控请求竞态、真实 Store/目录通知、实际钱包 SFC、团队回归及类型检查。构建、TEST 真机/H5 页面验收及推送由整合任务另行记录，不以本地通过代替实景验收。
