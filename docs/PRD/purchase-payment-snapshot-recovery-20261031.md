# 外部付款恢复时保留原收款快照

HDPAY/BSC/ERC20 付款单重新进入、页面重载或从 hosted 页面返回时，费用区统一读取原 intent 的服务端持久快照。原业务金额保留最多六位小数，收款本金两位；已提供的本金舍入差额保留正负号与原精度，且须与原业务金额及收款本金一致。历史响应未提供原业务金额和舍入差额时不推算或编造。

HDPAY 恢复界面继续展示该单锁定 FX 和整数 VND 总额；不重新取当前全局汇率、不重报价、不重建付款单。FX 缺失或非法、提供的原金额/舍入差额矛盾时只保留原键查询和错误状态，不开放错误的收款指引。三语文案区分原业务金额、收款本金和本金舍入差额。

此展示与合同修复不改变原金额、渠道费用、钱包 PIN 范围或 provider hosted 跳转。验证采用原 intent 的解析、重载恢复和本地构建页面；不构成真实支付机构或链上转账验收。

新付款确认前将原报价 paymentMethod 与 network 持久化到账号内原命令记录；创建、查询及重载恢复的付款单即便具有同一 key / quoteId，也必须精确匹配该渠道和网络，否则不展示返回地址，保留原命令继续查询。历史记录未保存渠道/网络时只按原 key / quoteId 恢复，首次校验通过的原单快照随即持久化，之后不得改网。接口拒绝数组、对象等非字符串 paymentMethod。
