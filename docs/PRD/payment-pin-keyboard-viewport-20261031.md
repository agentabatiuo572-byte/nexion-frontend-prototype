# PIN弹层键盘与安全区

钱包支付PIN弹层在普通、多件和展开明细时，标题/关闭按钮保持在实际状态栏安全区下方，正文独立滚动；弹层使用键盘上方的可见高度，键盘收起后恢复。内容不能把标题或PIN输入永久推到屏幕外。

App复用真实statusBarHeight和键盘高度事件，关闭该弹层输入的原生自动上推以避免重复pan；窗口已因键盘缩小时不重复扣除键盘高度。H5/Lite使用visualViewport可见高度/偏移。窗口/浏览器可见区监听仅在弹层可见时存在；组件保留原生键盘高度缓存，确保已开键盘时重开弹层仍正确，组件卸载时清理。窗口缩小先于键盘高度到达时仍保留完整无键盘基准，避免重复扣减。

只调整布局与输入定位：PIN规则、设置/再次付款流程、次数、锁定、业务金额、明细、取消与恢复身份不变。设置页独立PIN输入保留原自动上推默认值。App原生多件实景复验与H5合成浏览器证据分开记录。
