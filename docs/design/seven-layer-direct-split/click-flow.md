# 网络版税点击流与验收

依据已批准七层直属拆分规格及 app-royalty-v2.png；复用现有 Team 与规则入口。

| 触发 | 行为 | 结果/失败出口 |
|---|---|---|
| Team网络版税入口 | 原unilevel路由 | 默认直属购买、七层购买总额、两币记录 |
| 期间 | 清分页并重读当前类别 | 加载、空态、失败重试；保留期间 |
| 直属购买 | unilevel filter=direct | L1来源组；hero为购买唯一全量聚合 |
| 网络购买 | unilevel filter=extended | L2–L7现行及历史账；同一snapshotAt |
| 设备收益 | direct-referral kind=device_earning | 先筛选后分页；hero改设备汇总 |
| 加载更多 | 相同类别、期间、snapshotAt下一页 | 防重复点击、追加去重、失败重试 |
| 规则介绍 | 已发布说明路由 | 模板相容；失败重试和返回 |
| 返回团队 | 原Team | 对碰、等级、培育、领导池、关系网络保持 |
| 切账号/环境 | 清快照重读 | 丢弃晚返回 |

缺价标等待计算；累计已到账不冒充可提现。zh/en/vi、暗亮、320px、大数和键盘须实景验证。设计图示例不写运行默认值，可见品牌仅UVEL，NEX币种保留。
