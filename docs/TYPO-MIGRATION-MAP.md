## 风险面(整改时逐批盯)

1. **≤11.5px 存量 308 处全部升 12**:chip/badge/cap-label 变大 5-20%,窄容器(排行榜行、状态 chip 群、tabbar)有溢出/换行风险 → 每批走查必须盯小组件密集页(earn 设备卡、team 排行、me 徽章墙)。
2. **hero 48→56**:320-360px 视口可能换行 → 按规范 §7.2 小屏降 44,落地用媒体查询或容器查询,不写死两套页面。
3. **13.5→13 与 12.5 分流**:12.5 的 81 处需逐处判「理解决策内容 or 纯标签」,不能机械替换。
4. **行高显式化**:存量大量 inline 无 line-height(继承),补档位行高会改变纵向节奏 → 与间距阶梯(space token)一批调,防"只改字不改距"的半成品感。
5. **哨兵接线**:verify 的 `value-ladder` 棘轮 matcher 当前按 9 档判档间值 → **B0 必须先升级 matcher 至 14 档并重生成基线**(棘轮方向保持:存量违例只减不增),否则 B1 首页一迁移(34/56 等新档)即假红。dom-qa 最小字号地板同理,按批收紧,LEDGER 黄灯不增。
