#### [FEAT-BRAND1] APP 识别 UVEL
① 用户故事：作为 APP 访问者，希望在应用、设备展示和分享图片上看到一致的 UVEL 名称与标志，以便确认所使用的品牌。

② 验收 GWT：
- Given 基线一致，When 打开 APP 并浏览品牌入口，Then 名称为 UVEL，LOGO 来自指定交付包且无拉伸。
- Given 已有旧账号与 NexGridBox 设备记录，When 升级后登录、访问设备/订单并刷新，Then 品牌展示更新，账号、余额、订单 ID 和推荐码不变。
- 异常1：Given 图片或画布生成失败，When 生成分享图，Then 保留原有失败反馈和重试；不能产生缺 LOGO 却显示成功的图片。
- 异常2：Given 自定义设备名或尚无设备，When 浏览设备/分享入口，Then 不更改自定义名称、不伪造设备，既有空状态和模板可用性保持。
- 异常3：Given 320px 窄屏或三种语言，When 切换主题及进入独立页，Then 品牌不遮挡操作、图片成功加载、页面无新溢出。

③ 数据字典：品牌展示常量 UVEL；产品展示前缀 UVELBox/UVELRack；交付 PNG 来源固定。N/A（无新增业务字段）。

④ 状态机：N/A（不增加业务状态或改变合法动作）。禁止借改名重置存储、更改币种、替换未知域名或改写自定义资料。

⑤ 交互原型与多状态覆盖：默认态展示 UVEL；空状态沿用现有引导；加载态沿用原有反馈；报错/极限态覆盖资源失败、画布失败和窄屏长文。
