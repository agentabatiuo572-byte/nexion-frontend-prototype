## T2 · [机制] 费用引擎重写:固定费 + 显式抵扣意图

**范围文件**:`src/store/nex-faucet.ts` · `scripts/selfcheck-withdrawfee.mjs`

**做什么**:`computeWithdrawFee` 重签名重实现——入参 `(amountUSDT, userNex, offsetWithNex: boolean, nexFeeOffsetRate, networkConfirmFeeUsd: number)`(单网络费值,由调用方按当前绑定网络取键);产出 `{ networkConfirmUsd, requiredNex, nexBurned, feeWaived, actualFee, netReceive }`,删 penaltyFee/grossFee 概念。核心规则:
- `networkConfirmUsd`:金额 ≤0 → 0(保留「没转账就没这笔费」不变量);>0 → 配置值原样(不再按金额比例)。
- `offsetWithNex=false` → nexBurned=0、actualFee=networkConfirmUsd(**server 侧无此意图永不烧 NEX**,规格 ③)。
- `offsetWithNex=true` → `nexBurned = min(userNex, ceil(fee/offsetRate))`(取整按拍板项1),`actualFee = max(0, fee − nexBurned×offsetRate)`(server 权威校验等式,不出负数),部分抵扣自然成立;NEX=0 → 烧 0。
- `computeNetworkFee`(比例+夹逼)删除;`isNetworkFeeConfigUsable` 换代(T1)。
- 🔴 文档头注释同笔更新为新公式。

**AC**(规格 ② 阳光1/2 + 异常1 + ③ 校验等式)
- [ ] selfcheck-withdrawfee.mjs 全部重写为新等式行为断言:默认不抵扣(TRC20 提 $100 → 费 $1、到手 $99;不出现 penalty 字段);勾选全抵(NEX 充足 → actualFee 0、到手 = 全额);部分抵(NEX 折算 < 费 → actualFee = 差额,≥0);NEX=0 勾选 → 烧 0;金额 0 → 费 0;ERC20 $5 键值正确取用;`|actualFee − max(0, fee − nexBurned×0.4)| ≤ 0.0001`
