# H5 最终修改汇总

更新时间：2026-06-26

说明：本文只记录当前代码中最终保留的修改结果；中途撤回、重复试错、被后续覆盖的调整不记录。

## 1. H5 预览方式

- 当前 H5 通过本地服务预览：`http://localhost:5173/#/`。
- 不使用 `file:///.../index.html` 直接打开项目入口文件，直接打开会导致 H5 资源无法按 Vite/uni-app 方式加载。

## 2. 外壳与全局布局

- 设备外壳按 `414 x 874` 作为目标尺寸，桌面预览时居中展示。
- 顶部 Status Bar 保留 `44px` 高度，并生成 iPhone 风格时间、信号、Wi-Fi、电池状态。
- Header Row 固定为 `52px` 高度，所有页面标题居中对齐。
- TabBar 高度为 `64px`，Home Indicator 高度为 `20px`。
- 页面左右边距使用 `20px / 24px` 的响应式范围。
- 卡片与模块间距最终统一为 `16px`，不把投影视为间距。
- 弹窗、客服入口、底部控件都限制在设备外壳内。

## 3. Header Row

- 首页 Header 标题最终为“首页”，版本号已移除。
- Header 左侧 Logo 替换为上传的 Nexion 横向 Logo：
  - 浅色模式使用蓝色 Logo。
  - 深色模式使用荧光绿/白色 Logo。
- 搜索和消息按钮为 `40px x 40px` 圆形玻璃按钮，无描边。
- Header 底部取消描边，仅保留滚动后的投影区分顶部区域。
- 浅色模式 Header 滚动投影使用 `rgba(24, 84, 180, 0.2)`。

## 4. 字体与数字排版

- 字体体系最终使用：
  - Display / Amount：`Space Grotesk`
  - Body / Interface：`Inter`
  - Numbers / Address：`JetBrains Mono`
  - Brand Accent：`Rajdhani`
  - 中文：`PingFang SC / Noto Sans SC`
  - 日文：`Noto Sans JP`
  - 韩文：`Noto Sans KR`
  - 阿拉伯语：`Noto Sans Arabic`
- 大金额数字使用 `Space Grotesk`。
- 金额、百分比、Token 数量、倒计时、算力等数字启用 `font-variant-numeric: tabular-nums`。
- 当前小于 `12px` 的现有字号按最终要求保留，不再统一上调。

## 5. 主题颜色与实时状态

- 深色模式中的“今日收益 / 动态 / 网络脉搏”实时标签统一为紫色：
  - 文字和动态点：`#8E72FF`
  - 背景：`rgba(142, 114, 255, 0.2)`
- 浅色模式中的“动态 / 网络脉搏”实时标签使用绿色。
- 今日收益浅色模式光晕改为蓝色 `#246BFE`。
- 深色模式分界线和弱信息对比已增强，避免在深色卡片中不可见。
- 浅色模式通知界面改回浅色体系。

## 6. 客服入口

- 浅色模式客服入口使用上传的客服头像图片。
- 浅色模式客服入口周围光晕改为蓝色。
- 深色模式继续使用原深色客服形象。
- 客服入口固定在设备外壳内，并在内容密集区可收缩为更小入口，避免遮挡底部内容。

## 7. 代金券与按钮规范

- 代金券按钮中的文字和进入箭头作为一个整体居中。
- 进入箭头放在正方形外框内，外框尺寸与文字行高一致，箭头居中。
- 代金券按钮整体向右微调，文字与箭头视觉对齐。
- 纯文字链接样式保持原样，不套用按钮样式。
- 只有具备按钮形态的 CTA 才应用按钮样式和进入箭头。
- 浅色模式设备福利按钮最终与代金券按钮颜色一致。

## 8. 试用福利横幅

- 横幅在浅色模式下参考深色模式卡片结构，但使用蓝色体系。
- 小屏下标题可被右侧固定按钮挤压，文字自动优化换行，不再与按钮重叠。
- 右侧“马上领取”按钮保持固定尺寸，按钮内容使用与代金券同类的文字加箭头对齐方式。

## 9. 首日奖励卡片

- 标题“首日奖励”使用与“网络脉搏”一致的标题参数。
- 大数字 `+500 NEX` 与本周任务奖励数字风格保持一致。
- `+500` 前的符号与金额数字等大，并使用收益增加色。
- 进度说明文字恢复显示，`3/6 进行中` 使用主文本色。
- “已完成”文案改为“进行中”。
- 浅色模式进度条颜色改为：
  - `0% #2F35FF`
  - `46% #126BFF`
  - `100% #18C8FF`
- 任务序号在圆圈内居中。
- 未完成任务行增加轻背景，背景色跟随任务分类颜色。
- 任务名和分类在小屏幕下支持两行布局，分类贴近任务名，避免挤压重叠。
- 任务行最小高度为 `44px`。

## 10. 本周任务卡片

- 卡片最终高度为 `190px`。
- 图片保留偏移，底部与卡片下边对齐。
- 图片尺寸恢复为最终布局需要的 `220px x 220px` 区域。
- 倒计时文字保留：
  - 字号 `12px`
  - 字重 `500`
  - 颜色 `#9B89E0`
- 浅色模式倒计时使用 `rgba(245, 243, 252, 0.8)` 胶囊背景。
- 深色模式只隐藏倒计时胶囊背景，倒计时文字继续显示。
- 本周任务按钮高度为 `40px`，文字与箭头按代金券按钮方式居中对齐，按钮尺寸不被改变。

## 11. 动态 / 收益模块

- 分段按钮下方列表下移 `4px`。
- 动态列表第三竖列与第二竖列距离调整为 `8px`。
- 动态列表最前方时间：
  - 深色模式：`#F5F7FA`
  - 浅色模式：`#B8C0CC`
- 深色模式实时标签最终使用紫色。

## 12. 网络脉搏

- 标题“网络脉搏”参数作为首页多个模块标题的统一参考。
- 右上角实时状态保留动态小点。
- 右上角实时状态在深色模式使用紫色，在浅色模式使用绿色。
- “全球网格 · 实时”这一栏中的左侧状态文字已简化，仅保留需要的信息层级。
- “你的排名”区域去掉排名前的符号，避免与折线图重叠。

## 13. 算力市场

- 删除算力市场卡片外描边。
- 折线图样式参考网络脉搏中的折线图。
- 市场列表采用固定竖列布局，减少列间空白：
  - 类型列：`40px`
  - 模型列：`80px`
  - 1h 折线列：`64px`
  - 价格列：`82px`
  - 24h 列：`42px`
- 模型列最大宽度为 `80px`，超出用省略号。
- 表头与内容列左对齐。
- 价格列统一保留小数点后 `6` 位。
- 小屏幕下缩小列宽和字号，保证信息不重叠。

## 14. 算笔账 / NEX 价格 / 网格实时

- 算笔账卡片删除外描边。
- NEX 价格卡片删除外描边。
- NEX 价格卡片折线图高度调整为 `40px`。
- 网格实时相关卡片删除外描边。
- “我的算力队”和“网格实时”中设备图片预留尺寸调整为 `44px`。
- 手机设备图标替换为真实手机图片，最终展示尺寸为 `48px x 48px`。
- 手机图标右下在线小点描边颜色与背景一致，减少白边突兀感。

## 15. 领导奖池

- 首页领导奖池卡片保留“本周奖池 · 平台交易额的 5%”说明文字。
- 卡片排版调整为左侧标题、主金额、说明，右侧为 `V3+ 解锁` 按钮。
- `V3+ 解锁` 按钮中加入进入箭头。
- 删除重复的周池、平台周交易 5%、7 天后结算类冗余说明，只保留最终清晰版信息。
