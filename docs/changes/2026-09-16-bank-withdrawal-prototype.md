# 银行卡提现原型界面融入正式 App

沿用 `97d7aeb` 已接入的银行卡业务、报价与原单恢复，在现有 `wallet-withdraw-bank.vue` 上还原独立 HTML 原型的收款账户、金额、确认、结果四步布局。账户卡片、主按钮、到账 VND 大字、报价倒计时和核对勾选使用 App 主题；没有移入原型的场景选择器、示例账户、金额、费率或模拟到账逻辑。

账户状态由后端 enabled、beneficiary.canWithdraw 和 unresolvedIntent 决定。首次绑定与换卡即时生效，换卡短信规则继续使用现有绑定流程。原型里的核验和等待规则不恢复。

金额页解析现有 config.policy 中的 PC D7 单笔上下限、手续费配置；后端新增 capacity，复用实际扣款时的已释放余额、余额比例和越南自然日次数。单笔限额、可提现余额、每日次数分开展示，“全部”取单笔上限与真实可提现额度中的较小值。缺字段或读取失败不使用示例值；可手动刷新，跨过后端返回的每日重置时间后自动重新读取。

报价及到账金额仍以服务端结果为准。修改确认金额前先在服务端封存旧报价；核对勾选不写入持久存储，报价恢复后必须重新确认。响应丢失时仅恢复原单。已到账或退款仍需要匹配的账本证据。

目标验证覆盖动态 PC 限额、最大金额、每日次数与跨日恢复、未绑定/不可用账户、报价过期、确认勾选、响应丢失、原单恢复、三语言和明暗主题。真实资金操作不属于本次界面验收；隔离浏览器脚本仅替换网络传输。
