## 扫描口径

扫 `.vue` 的 `<template>`(剥注释)四类:① `<text>` 裸文本 ② `placeholder="字面量"`
③ `aria-label="字面量"` ④ script 里的 `|| "兜底文案"`。

原始命中 110 处 → 剔除品牌词/单位/纯数值后 **66 处需人工判定**。

## 🔴 判定:哪些不该翻(防洁癖)

**跨语言恒定的东西翻了反而错**,以下**明确不动**:

| 类 | 例 | 理由 |
|---|---|---|
| 品牌与产品名 | `NexGrid` · `NexGridBox S1` · `NexGrid Genesis Node` · `NEX` · `USDT` · `NEX / USDT` | 品牌标识跨语言恒定 |
| 支付/合规标准名 | `Visa / Mastercard` · `PCI DSS Level 1 · 3DS 2.2` · `SOC 2 Type II` · `GDPR · MSB` · `CertiK audited` · `Chainalysis KYT` · `MiCA` · `FATF` · `FinCEN` | 专有名词,业界不译 |
| 版本与数值 | `NexGrid · v3.2.0 · build 6824` · `+$215/sec` · `+2,000 NEX` · `1.00 USDT` | 数据不是文案 |
| 格式示例 placeholder | `0.00` · `1234 5678 9012 3456` · `MM/YY` · `123` · `•••` · `10001` · `YYYY-MM-DD` | 输入格式示意,各语言一样;翻了反而看不懂 |
| 产品渲染图丝印 | `CLOUD SHARE` · `DISTRIBUTED · NO HARDWARE` | 那是**图形元素**(印在设备外壳上的字),不是界面文案 |
