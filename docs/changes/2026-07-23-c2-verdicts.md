> **「任何带背景色填充的卡片/板块一律零 border」**,border 只属透明容器(分组 hairline / empty-state 虚线);

**判据(全部来自规范原文,不是我调的参)**:
- 违例 = 该元素**自身有可见填充**(bg alpha ≥0.03 或有渐变)**且有可见描边**。
- 分级:`full`(≥3 边 = 盒子描边)进硬门;`partial`(1-2 边 = 行分隔线)只列不拦。
- 三条内建豁免,判据均出自《03》:① chrome 身份(TabBar/Header/浮层/下拉刷新指示器)
  ② dashed/dotted(empty-state 虚线惯用法,填充卡不会用虚线)③ ≤16px 圆形「隔离描边环」
  (状态点用底色描边做分隔,是技法不是卡片描边 —— 主人在任务书里明确列的豁免)。

**为什么是运行时门**(承 C1 教训):静态 grep 只能钉「我已经想到的写法」——
border 可写成 `border:` / `border-top:` / 驼峰 `borderColor` / UnoCSS class / CSS 类 / 继承;
bg 可以是 color / gradient / token。用写法找角色必漏。本门只问渲染结果。
