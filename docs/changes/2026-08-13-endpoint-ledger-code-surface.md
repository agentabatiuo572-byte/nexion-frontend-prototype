## 问题

`scripts/endpoint-citation-sentinel.mjs` 判「注释里写的接口地址必须在台账有据」,而它的扫描逻辑是:

```js
if (!isComment[i]) return;   // ← 只看注释行
```

于是 `src/api/*.ts` 里**真正发出去的地址**——`path: "/api/x"`、`` `/api/x/${id}` ``——
**一条都不在扫描面里**。这不是「有人忘了登记」,是**这道门看不见它们**。

代价不是假设的:一个已被 PRD 改名的卡时代旧端点(`/api/trial/redeem-early`)
零调用地躺在接口层近两周,这道门一次都没响 —— 因为它是代码字符串。

更隐蔽的一层:台账规则②是「台账里有、**注释**里没有 → 判红」。
所以就算有人想登记这类端点,登记完反而会**因为注释里没有引用而判红** ——
这类端点在旧判据下**根本无法登记**。

## 焊门

两个扫描面,**共用同一本台账**(分两本必然各自漂):

| 面 | 扫什么 | 判什么 |
|---|---|---|
| 注释面(原有) | 注释行里的 `/api/...` | 写对没写对 |
| **代码面(新增)** | 非注释行的字符串字面量与**模板串**(单/双引号 + 反引号) | **真发出去的地址**有没有据 |

**路径参数段一律折成 `:param`**:代码写 `${encodeURIComponent(id)}`、台账写 `:id` / `:userId`,
指的是同一个位置。不折的话两边永远对不上,台账就得为每种写法各存一条 —— 那是在造漂移源。

配套改了三处判据:
- **①' 新增**:代码面出现未登记地址 → 判红并**点名 + 给出文件行**。
- **② 放宽**:台账条目「还活着」= 注释面命中 **或** 代码面命中。
  只看注释面会把「只在代码里发、没写注释」的条目误判成过期条目。
- **③ 拆成两条**:两个面**各判各的空集**。合起来判的话,注释面还有命中就能把代码面整个瞎掉盖住。

**代码面跳过测试文件**(`*.test.ts` / `*.spec.ts`):契约测试会把路径参数写成固定夹具值
(`…/courses/h3-live-20260722/quiz`),那是同一个端点的一个样本、不是新契约;
登记它等于把夹具 id 焊进台账,夹具一改台账就过期。
⚠️ **注释面不跳过**(测试里的注释同样会写错地址),且**跳过数打进 PASS 行**,不许静默增长。

### ⚠️ 红测过程里我自己翻的三次车(比结论更值得记)

1. **M1 第一次报「没红」——是我的 grep 写错了,不是门坏了。**
   我的模式是 `未登记的接口调用 .api/redtest`,而实际输出是 ``…调用 `/api/redtest/…``:
   `.` 吃掉了反引号,后面就对不上 `/api` 了。
   **按铁律先证「变异真的生效」→ 证到了 → 才去怀疑判据 → 结果发现该怀疑的是我的测试脚本。**
2. **M2 / M3 / M4 第一版变异根本没落盘**(sed 转义炸了 / bash 单引号里的反引号炸了),
   而我的检查写成了 `grep … | head -2 && echo ✓` —— `head` 永远 exit 0,
   **于是三条全打了绿勾**。这是**红测脚本自己的假绿**,和它要防的毛病一模一样。
   改法:变异器独立成文件,**变异不生效就 exit 2**;判定只看 `grep -q` 的退出码。
3. **M1 的还原脚本 `head -n -4` 多删了一行**,把 `trial-api.ts` 最后一个 `}` 削掉了。
   靠还原后比对 hash 发现(不等于干净态),回源确认差异只有那一行后修复。
   **教训:还原也要有证明,不能默认「我删回去了就等于没动过」。**
