# Liquid Glass 接入与优化清单

## 采用的开源实现

- [lollipopkit/liquid-glass](https://github.com/lollipopkit/liquid-glass)，固定 core 0.2.1：计算圆角玻璃的位移与高光贴图；未引入其 Vue 包装层或全局 CSS reset。
- [lucaperullo/simple-liquid-glass](https://github.com/lucaperullo/simple-liquid-glass)，固定 5.3.0：外置导航在不支持 SVG 背景折射的引擎上使用 WebGL。
- 两项均按各自 MIT 许可接入。完整许可及内嵌第三方声明保存在 LIQUID-GLASS-NOTICES.txt，构建时一并输出。
- core 0.2.1 会在导入时提前启动 Worker，与所用的 `backend: "ts"` 无关。安装脚本只移除这条未使用的启动语句，统一覆盖 H5 与 App renderjs；版本或上游结构变化会让安装明确失败，要求重新核验。光学算法保持原样。
- WebGL 依赖的 HTML 克隆会连续执行微任务，复杂页面可阻塞点击与绘制。`postinstall` 对 5.3.0 的 ESM/CJS 加入共享 5ms 时间预算，分段让浏览器绘制，保持原克隆次序与光学算法。每次刷新在一张截图后结算，期间的新变化合并为下一批，避免持续计时页面在失败后永远等不到恢复。补丁校验原始 SHA256，重复安装幂等；上游或补丁字节变化时明确失败。安装后已有开发服务须重建 Vite 依赖缓存，不能只靠页面热更新。

## 版本与平台边界

当前 DCloud H5 编译插件将 vue 重定向至 @dcloudio/uni-h5-vue，实际版本为 3.4.21；App 由基座提供 Vue。只更新项目 vue 依赖不能把整套运行时升级到 3.5。光学渲染不依赖 Vue 3.5，因此保持现有 DCloud 编译链。

材质和选中底座在 renderjs 视图层运行，显式 hostId 定位宿主；App renderjs 的空 Vue 实例不作为页面 DOM。Chrome 使用 SVG 背景滤镜；WebKit 的外置导航捕获随滚动移动的内容节点并折射。内容内的分类控件在该路径采用模糊、高光和边缘材质，避免递归捕获包含自身的背景。WebGL 更新期间保持有效帧；捕获失败或图形上下文丢失时隐藏旧纹理并退回实时磨砂，截图和图形引擎均恢复后再显示折射。

选中块以同一条阻尼弹簧轨迹移动，速度控制横向拉伸及纵向压缩；连续点击保留当前位置与速度。等宽分类及底部导航支持横向拖动，松开后提交一次选择，纵向滚动及移出取消保留。横向滚动、换行和纵向分类保持原来的滚动方式。跨页面导航在首帧接续出发位置；H5 还接续出发速度。正文、图标文字和触控区不随玻璃形变。

玻璃底色在明暗主题中均提供 82% 遮盖，选中块增加稳定底色，保留低模糊折射。曲面贴图采用 2–3 倍整数采样，兼容分数屏幕缩放；高光柔化并用半像素内沿替代叠加硬描边。导航的整块玻璃背景和分类底座随点击、拖动拉伸并回弹，使用现有弹簧与合成层变换，不逐帧改布局或重建纹理。跨页同时接续背景的形变与速度；减少动态时立即复位。

LOGO 无玻璃背景；内容离开顶部 16px 后淡出，回到顶部 8px 内才恢复，避免下滑中与正文重叠。搜索和消息保持固定位置及玻璃背景。滚动观察在视图线程执行，兼容 H5 与 App renderjs。

系统减少动态效果时停止底座与按压动画；减少透明或提高对比时使用实色底。WebKit 浏览器和 App 构建可由本仓验证，iOS/Android 真机性能与辅助技术仍需设备验收。

原有 General Sans、Manrope、JetBrains Mono 改为随应用加载，保持字体与字重，不再依赖外部字体 CSS 完成首屏。字体原文件与各自许可置于 `src/static/fonts/`；General Sans 按 ITF FFL 自托管，另两项按 OFL 保留声明。材质回归同时检查字体实际加载、失败请求与资源 HTTP 错误。

## 内容卡与弹层材质

`src/styles/glass-surfaces.css` 提供 `nx-glass-card`（24px 内容外壳）、`nx-glass-sheet`（28px 弹层外框）和 `nx-glass-action`（只回弹装饰层的短入口）。材质从原 `nx-home-glass-panel` 提炼，后者复用相同 fill/edge 参数；已有设备、券插图与跳转保持不变。

内容使用 94% 表面底色，弹层使用 98% 表面底色，加中性内沿、顶部高光和底部暗部。这是静态厚玻璃视觉，不是实时背景折射，也不调用大卡尺寸的光学贴图。现有 `LiquidGlass` / `GlassSegments` 继续负责导航与短选择器；复投计算器期限选择复用 `GlassSegments`。

外壳显式引用 `--nx-glass-fill` / `--nx-glass-radius` / `--nx-glass-edge`，不更改全局 `--v5-surface`。内层账单、图表、输入、聊天、QR、纸票据和导出海报保留原语义；已有去卡片化列表不逐行加壳。颜色取当前主题变量，减少透明/提高对比时改用实底，减少动态时停止装饰按压。

## 验证入口

- `npm run type-check`：Vue / TypeScript 静态类型检查。
- `npm exec -- vitest run src/components/glass-segments.behavior.test.ts src/lib/chassis-scroll.test.ts`：分段选择的语义、键盘选择、disabled 跳过、焦点定位与当前 tab 回顶逻辑；App 的序列化事件和 WebView 调用使用模拟对象验证。
- `node --test scripts/how-entry-navigation.contract.test.mjs scripts/native-svg-icons.test.mjs`：导航出口、返回时关闭瞬时弹层与原生 SVG 构建转换契约。
- `node node_modules/@dcloudio/vite-plugin-uni/bin/uni.js build -p app`：App 编译检查；设备上的触摸、渲染与辅助技术另行验收。
- `npm run verify`：执行 `verify-chain.mjs --full` 全量门；提交前及最终干净提交的验证要求以当前工作区规则与 hooks 为准。

本仓现有定向测试覆盖上述逻辑和契约，尚无 `test:tabbar-glass` 专用脚本；60 组主导航矩阵、91 路由、双浏览器材质/恢复和逐帧运动不属于这些定向测试的已覆盖范围。Prototype 的测试与截图只能作为参考，正式 App 的验收记录须标明本次提交、运行入口、页面和设备。

现场操作五个主导航、等宽/横向滚动/换行/纵向分类、搜索返回、消息抽屉和主题弹层，检查快速反向切换、重复点当前 tab 回顶、真实触摸只提交一次、取消不提交、纵向滚动不误选、键盘焦点、LOGO 隐藏恢复、横竖屏及后台恢复。运动验收记录选中块与背景的拉伸、回弹和跨页接续，确认文字与触控区稳定。需要证明折射、文字对比度或 DPR 兼容时，另保存开启/关闭位移的像素差、至少 4.5:1 的对比度测量，以及 DPR 1/2/2.625/3、明暗主题、Chromium/WebKit 的实际结果；策略标记和最终对齐本身不构成这些证据。
