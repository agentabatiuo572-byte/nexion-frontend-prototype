# Liquid Glass 接入与优化清单

## 采用的开源实现

- [lollipopkit/liquid-glass](https://github.com/lollipopkit/liquid-glass)，固定 core 0.2.1：计算圆角玻璃的位移与高光贴图；未引入其 Vue 包装层或全局 CSS reset。
- [lucaperullo/simple-liquid-glass](https://github.com/lucaperullo/simple-liquid-glass)，固定 5.3.0：外置导航在不支持 SVG 背景折射的引擎上使用 WebGL。
- 两项均按各自 MIT 许可接入。完整许可及内嵌第三方声明保存在 LIQUID-GLASS-NOTICES.txt，构建时一并输出。
- core 0.2.1 会在导入时提前启动 Worker，与所用的 `backend: "ts"` 无关。安装脚本只移除这条未使用的启动语句，统一覆盖 H5 与 App renderjs；版本或上游结构变化会让安装明确失败，要求重新核验。光学算法保持原样。
- WebGL 依赖的 HTML 克隆会连续执行微任务，复杂页面可阻塞点击与绘制。`postinstall` 对 5.3.0 的 ESM/CJS 加入共享 5ms 时间预算，分段让浏览器绘制，保持原克隆次序与光学算法。每次刷新在一张截图后结算，期间的新变化合并为下一批，避免持续计时页面在失败后永远等不到恢复。补丁校验原始 SHA256，重复安装幂等；上游或补丁字节变化时明确失败。安装后已有开发服务须重建 Vite 依赖缓存，不能只靠页面热更新。

## 版本与平台边界

当前 DCloud H5 编译插件将 vue 重定向至 @dcloudio/uni-h5-vue，实际版本为 3.4.21；App 由基座提供 Vue。只更新项目 vue 依赖不能把整套运行时升级到 3.5。光学渲染不依赖 Vue 3.5，因此保持现有 DCloud 编译链。

材质和选中底座在 renderjs 视图层运行，显式 hostId 定位宿主；App renderjs 的空 Vue 实例不作为页面 DOM。Chrome 使用 SVG 背景滤镜；WebKit 的外置导航捕获随滚动移动的内容节点并折射。内容内的分类控件在该路径采用模糊、高光和边缘材质，避免递归捕获包含自身的背景。WebGL 更新期间保持有效帧；捕获失败或图形上下文丢失时隐藏旧纹理并退回实时磨砂，截图和图形引擎均恢复后再显示折射。

选中块以同一条阻尼弹簧轨迹移动，速度控制横向拉伸及纵向压缩；连续点击保留当前位置与速度。等宽分类及底部导航支持横向拖动，松开后提交一次选择，纵向滚动及移出取消保留。横向滚动、换行和纵向分类保持原来的滚动方式。跨页面导航在首帧接续出发位置；H5 还接续出发速度。正文、图标文字和触控区不随玻璃形变。

LOGO 无玻璃背景；内容上滑超过方向阈值后淡出，下滑或回到顶部恢复。搜索和消息保持固定位置及玻璃背景。滚动观察在视图线程执行，兼容 H5 与 App renderjs。

系统减少动态效果时停止底座与按压动画；减少透明或提高对比时使用实色底。WebKit 浏览器和 App 构建可由本仓验证，iOS/Android 真机性能与辅助技术仍需设备验收。

原有 General Sans、Manrope、JetBrains Mono 改为随应用加载，保持字体与字重，不再依赖外部字体 CSS 完成首屏。字体原文件与各自许可置于 `src/static/fonts/`；General Sans 按 ITF FFL 自托管，另两项按 OFL 保留声明。材质回归同时检查字体实际加载、失败请求与资源 HTTP 错误。

## 验证入口

- npm run type-check
- npm run test:tabbar-glass（核心行为、60 组主导航矩阵、双浏览器材质/恢复、逐帧运动/拖动/LOGO、分类/辅助入口与 91 路由）
- node node_modules/@dcloudio/vite-plugin-uni/bin/uni.js build -p app
- npm run verify（最终提交的全量门）

浏览器依赖：npx playwright install chromium webkit。测试产物保存在忽略目录 .codex-runtime/liquid-glass/。真实折射用开启/关闭位移的像素差证明，同时测量中心细节对比及边缘位移，防止过量模糊被误报成 Liquid Glass。运动验收记录每一帧的位置、尺寸、跨页接续和快速反向轨迹，检查真实触摸只提交一次、取消不提交、滚动不误选，并拒绝跨页迟到或跳回旧槽；策略标记或最终对齐本身不作为动效证据。
