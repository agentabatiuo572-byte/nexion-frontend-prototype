# H5 手机入口交接

H5 分支中的 onboarding/connect 和 onboarding/estimator 直接跳转注册成功下载页，不在页面初始化时执行本地硬件估算或登记。普通注册礼保持独立规则。

全量 10/10 和手机平台 9 个浏览器用例通过。此仓为现有网页版实现，不能以其浏览器结果证明正式 Android 硬件密钥或真实后台联调通过。

完整跨仓提示词见 [后端交接](https://github.com/agentabatiuo572-byte/nexion-backend/blob/test/docs/phone-calibration-handoff.md)。本次不部署远端，后续由同事执行真机及多端验收。
