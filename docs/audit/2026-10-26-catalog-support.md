# 活动机型联动、客服浮标与浅色头像

## 范围与依据

本轮按用户新增要求处理：购机赠礼/升级建议图片跟随后台机型；首页、专区、团队恢复右下角客服悬浮入口；新增同角色浅色头像。团队首购活动中同类固定机型图一并修复。沿用已确认黑灰主题、圆盘商品素材、底部Liquid Glass和既有业务推荐算法。

消息气泡的状态位置、左右线性入场仅加入队列MSG-01/02，尚未实施。不将全站历史未覆盖项或原生实景记为本轮完成。

## 实现

- 购机主图与赠品按首条正在展示的后台规则分别确定SKU，再读取权威目录imageUrl。角色槽位固定，缺主图不会把赠品顶到主图；同SKU/同URL也保留两个角色。邀请人奖励不冒充买家赠品。
- 团队首购展示活动购买SKU，升级建议分别使用实际基础设备/目标商品的图片；不使用S1合成图或phone本地图兜底。圆盘来自目录发布的整图，aspectFit显示全图；缺图与失败使用中性占位。
- 新图片组件按账号、epoch、作用域、SKU、URL与刷新批次隔离请求；原生缓存重试也有attempt隔离，旧load/error和卸载后事件不能污染新图。刷新可恢复同URL图片。
- 完整发布Banner仍优先，解码成功后才隐藏组合图；其旧事件同时校验账号、语言、活动版本和刷新批次。完整Banner内的机器图由后台发布内容负责，后台需保持海报与规则一致；前端不拆解位图内的机型。
- 首页和团队可见时重新读取活动/目录；团队刷新以最新活动列表替换旧规则、撤下暂停/移除活动，隐藏和切账号撤销旧读。目录正在读取时复用共享请求，失败后可以重试，不匿名请求私有目录。
- 首页/专区/团队各保留一个48px客服浮标，相对实际导航高度上移12px；未读仅统计人工客服/顾问，零未读也可进入“服务”页。滚动时淡出并停止命中，停止后恢复；APP视图层的data-scrolling也有对应样式。
- 浅色主题使用新增银白角色和轻阴影浅底座，深色保留原角色；跟随resolved主题。资源来源与提示见[生图记录](2026-10-26-catalog-support/avatar-generation.md)。

## 独立审查发现及回修

1. 主购缺图导致赠品升格、失败URL长期被排除、旧图片事件污染、团队固定图：改为固定角色和分代图片加载器。
2. 团队刷新只读进度、保留旧rewardRules；首页/团队目录失败缺少恢复：补活动/目录刷新与页面显示/隐藏生命周期。
3. 团队旧166px插画框超出124px父框，裁切动态图片与占位：图片框改为父框100%，去掉负top与超尺寸，窄屏同样完整包含。
4. APP视图层滚动状态未连接浮标样式：消费既有data-scrolling状态，保留H5逻辑层淡出。
5. 实景发现商城浅色活动卡覆盖了背景但仍继承白色标题，文字对比不足：商城在自己的活动容器提供主题文字色，首页黑灰活动卡继续使用白色字。
