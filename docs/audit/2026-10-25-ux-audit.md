审查方法:
- 实景走查:430×932 视口,覆盖 5 个 tab(首页 / 赚取 / 商城 / 团队 / 我的)和关键链路(商品详情 → 结算两步、设备详情、消息、任务中心、账单)。也打开了浮层:试用弹窗、代金券、活动卡和活动规则弹窗。
- 代码与文档核对:设计系统量化盘点(2 个只读 agent);对照 PRD §5、`DECARD-SPEC`、`PAGE-SKELETONS`、`home-glass-20260928` 契约、`ALIGNMENT-LEDGER` 冻结清单、09-25 文案体检。
- 判定口径:按 CLAUDE.md「接上真后端对不对」。数值互相对不上多为 mock 脚手架所致,**不计缺陷**。「同名不同口径」「精度和单位不统一」「失败态外露」是真缺陷。

## 一、结论先行:5 个根因

1. **首页没有主任务,是功能货架。** PRD §5 本身就规定了 16 个 section,首页约 4,800px、5 屏。营销模块排在用户自己的状态前面:第一屏几乎全是代金券、试用、活动卡和手机提示,收益与设备被挤到下面。
2. **营销触点按页面堆,不按用户状态编排。**
   - 代金券横幅由 chassis 注入 4 个 tab。
   - 试用有 3 个入口。
   - 活动卡出现在首页和商城。
   - 设备对比出现在首页和赚取。
   - 行情出现在首页和赚取。
   - 同一信息全 App 反复出现,彼此还不衔接:结算页看不到代金券和赠品。
3. **5 个一级 tab 页从未去卡化。** DECARD 和 09 月的「扁平内容面」只做了二级页,5 个 tab 页在 `ALIGNMENT-LEDGER` 禁改清单里。结果是 tab 页仍是「一模块一张卡、卡里再套卡」,和已经扁平的二级页视觉语法割裂。
4. **没有组件原语。**
   - 卡片 / 面板约 49 种变体。
   - 区块标题 4 个组件,外加 49 处内联写法。
   - 主按钮至少 17 种实现,高度有 44 / 46 / 48 / 50 / 52 / 54,`.nx-btn` 圆角是 12 而非 pill。
   - 圆角值 37 种,只有 25 处用 token;字号 35 种,只有 24 处用 token;间距 token 0 引用。
   - 规范写了,但没有可复用的落点,所以每个模块各写一套。
5. **文案从系统视角出发。** 把条款、实现说明、失败态、规则字段直接搬给用户,同时又混着口语化的承诺式营销,语气两极分化。

### E. 合规与可信度风险(需主人拍板)

本节说的是上线风险,不是审美问题。

- **收益承诺式表述:** 「你将赚取 $7.00/天」「你能拿多少 $21 3 天到手」「开通即刻进账」「117× 更多」「质押 180% 年化」。建议一律改为「预估」并标注口径。
- **伪紧迫和伪社会证明:** 「仅剩 47 / 本周」「105 在看」「30 分钟售出 2」、购买跑马灯、「余 1000 席」。09-28 契约已经明令「禁止虚构紧迫」,真实上线时这些必须来自真实数据,否则删除。
- **传销语汇:** 对碰、族谱、领导池、版税网络、直推。这些词有应用商店审核风险;是否改用中性词由主人定。
- **规格可信度:** $649 的设备写着「4× RTX 4090 / 96GB / 1,200W」,懂行的用户会直接不信。FAQ 说「部署地点不固定」,结算页又写「新加坡数据中心」,前后矛盾。
- **设计 skill 与新契约冲突:** skill 快照第 23–25 条(入口用紧迫感、付费条款提交后才披露、弱化取消按钮)与 09-28 契约和 09-25 文案体检冲突,需要裁定以哪边为准。

## 三、最优解决方案

### 3.1 设计原则(全部方案由此推出)

1. **首页回答三件事:** 我赚了多少 → 设备都正常吗 → 有什么要我处理。增长和营销只占一个位置。
2. **一屏一主行动:** 每个视口最多 1 个满宽主按钮,其余用次按钮或文字链接。
3. **按状态编排触点,不按页面堆:** 同一个营销信息全 App 只有一个主入口,并且一路带到结算。
4. **静为常态,动为事件:** 每个视口最多 1 个持续动效;不自动轮播;倒计时只在最后 24 小时出现。
5. **用户视角、结果先行的文案:** 先说得到什么,再说条件;规则放进详情页。

### 3.2 五个 Tab 职责重划

| Tab | 唯一职责 | 收进来 | 移出去 |
|---|---|---|---|
| 首页 | 我的状态 + 待办 + 1 个活动位 | 待办清单(合并 6 类提示) | 行情、算力市场、设备对比、设备信息、$NEX、快捷四宫格、收益流水 |
| 赚取 | 收益与设备运营 | 收益明细、行情(唯一一处)、「更多赚取方式」(手机算力 / 质押 / 试用) | 顶部两个营销横幅、设备对比 |
| 商城 | 买设备 | 代金券入口(顶部一行「2 张可用 ›」)、活动 banner、设备对比(放在商品详情) | 首页里的商品信息卡 |
| 团队 | 邀请与佣金 | 本月佣金 hero 置顶;邀请只保留 1 个主按钮 | 重复的口号和隐私说明(移入规则页) |
| 我的 | 账户、钱包、设置 | 设置改为分组列表;安全提醒作为提示行 | 试用入口、代金券横幅;「开发者」移到「帮助与支持」底部或下线 |

全局规则:**chassis 不再给 tab 页注入代金券横幅**;试用全 App 只保留一个入口。
